# Security Research

Technical investigations into application security, AI security, and emerging attack surfaces.

I document vulnerabilities, analyze exploitation paths, and explore practical security engineering lessons.

## Research Areas

- **AI and LLM Security:** Agent execution, tool permissions, and prompt injection.
- **Vulnerability Research:** Root-cause analysis, exploitability, and security boundaries.
- **Cloud Security:** Identity, isolation, and infrastructure permissions.
- **Secure Execution:** Sandboxing, dynamic code execution, and untrusted input processing.
